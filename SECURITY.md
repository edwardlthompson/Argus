# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest on `main` | ✅ |
| older tags | ❌ unless noted in a release |

## Reporting a Vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Use GitHub private reporting: **Security → Advisories → Report a vulnerability** on this repository.

Include: description, reproduction steps, impact, and a suggested fix if you have one.

## What Argus will never do

See `docs/SAFETY.md` — no force-push, no history rewrite, no hard-delete of target repositories.
